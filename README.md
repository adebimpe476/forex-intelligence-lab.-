# Forex Intelligence Lab

Research-only quantitative forex project. This repository is being initialized for a reviewed v0.2 source import.

**Trading and live order execution are disabled.** No MT5 account connection, live data, or production trading endpoint exists.

Planned architecture: historical and bid/ask market data → strategy research → validated backtesting (LEAN candidate) → paper trading through an authorized MT5 adapter → mobile control dashboard.

The objective is statistically defensible profitability and risk control, **not an unverified 95% win-rate claim**.

See the incoming development branch for the source, historical-data provenance, unit tests and GitHub Actions.
